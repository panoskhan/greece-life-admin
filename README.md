# Greece Life Admin 🇬🇷

A free, independent, privacy-first guide to finding official Greek administrative services.

## What it does

Greece Life Admin helps people describe what they need in ordinary language, find a relevant official service, and understand the starting point without requiring an account or unnecessary personal data.

The project is a navigation layer. It does **not** replace gov.gr, provide legal advice, or represent the Greek government.

## Source policy

Important service links are taken from official Greek government sources. The starter registry records a review date for each entry. Information can change, so users should verify important details on the linked official service before acting.

## Current MVP

- English and Greek UI
- Natural-language keyword search
- Starter registry of verified official services
- Direct official-source links
- Review dates
- Responsive/mobile-first interface
- Privacy-first, no-account core experience
- Clear independent-project disclaimer

## Development principles

1. Official source first.
2. No unnecessary personal data.
3. Plain language over bureaucracy-heavy wording.
4. Never invent requirements, deadlines, eligibility, or outcomes.
5. Make review dates visible and corrections easy.
6. Keep the core experience usable without AI.

## Contributing

Contributions are welcome when they improve clarity, accessibility, engineering quality, or source accuracy. New service entries should include an official source URL and a review date. Do not add claims that cannot be verified.
